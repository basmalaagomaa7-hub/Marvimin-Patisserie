# Marvimin Patisserie Website

A responsive front-end website concept for Marvimin Patisserie.

## Included
- Marvimin's original logo and menu artwork (used without redesigning the logo)
- Real product photos and feedback images supplied with the project
- Light / dark mode with the brand-inspired palette
- Responsive navigation and mobile menu
- New-item showcase
- Interactive menu and shopping cart
- Cart saved in the browser with localStorage
- WhatsApp order-message generator
- Instagram + WhatsApp community links
- Original menu viewer

## Run locally
No build step is required.

1. Extract the folder.
2. Open `index.html` in a browser.
3. For the smoothest local experience, serve the folder with VS Code Live Server or another local static server.
